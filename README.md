## what is it

Weather is a library that offers weather-related commands and updates LIVE with the weather in all cities worldwide.

## what's inside

you can use the following commands with this library:
now - prints the city, temperature, humidity, and condition
temp - prints just the temperature
humidity - prints just the humidity
condition - prints the weather in words, like Clear or rain
rain - says if it is raining there right now
snow - says if it is snowing there right now
compare - prints a few cities one under the other, with temperature and condition
hottest - picks the hottest city out of the ones you typed
coldest - picks the coldest city out of the ones you typed
